# 📰 Berita Merah

**Berita Merah** adalah portal berita web modern yang menyajikan informasi dan berita terkini dengan antarmuka yang bersih, responsif, dan mudah digunakan.

🔗 **Live Demo:** [beritamerah.netlify.app](https://beritamerah.netlify.app)

---

## ✨ Fitur Utama

- 🚀 **Desain Responsif:** Tampilan optimal di berbagai perangkat (Mobile, Tablet, Desktop).
- ⚡ **Akses Cepat & Ringan:** Dideploy di Netlify untuk performa dan kecepatan muat yang tinggi.
- 📰 **Kategori Berita:** Navigasi berita yang terorganisir berdasarkan topik/kategori.
- 🎨 **Antarmuka Modern:** Desain UI/UX yang bersih dan fokus pada kenyamanan membaca.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, CSS3, JavaScript (atau sebutkan framework yang kamu pakai, misal: React / Vue / Tailwind CSS)
- **Deployment:** [Netlify](https://www.netlify.com/)

## 🚀 Cara Menjalankan Proyek Secara Lokal

Jika Anda ingin menjalankan proyek ini di lingkungan lokal:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username-kamu/nama-repo-kamu.git
   ```

2. **Masuk ke direktori proyek:**
   ```bash
   cd nama-repo-kamu
   ```

3. **Buka file `index.html` di browser** (atau jalankan perintah instalasi jika menggunakan framework):
   ```bash
   # Jika menggunakan npm / Node.js:
   npm install
   npm run dev
   ```
